# Governance

EvidenceKit begins with a simple primary-maintainer model.

## Primary maintainer

The primary maintainer is responsible for release integrity, security triage, review standards, roadmap coherence, and preservation of the project's public/private IP boundary.

Current primary maintainer:

- **Amir Mohammad Sarkheil** — GitHub: `AmirSarkheil`

## Changes

Non-trivial changes should arrive through pull requests. Schema and release-sensitive changes should have an explicit review trail, even when authored by the primary maintainer.

## Adding maintainers

Maintainer status is earned through sustained, reviewable contribution and is recorded in `MAINTAINERS.md`. No maintainer title is implied by contribution volume alone.

## Decision principles

1. Utility before visibility.
2. Evidence before claims.
3. Public contract before private implementation.
4. Compatibility changes are explicit and versioned.
5. Security and IP concerns may block or narrow a change.
